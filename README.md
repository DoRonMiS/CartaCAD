# CartaCAD

Parametric 3D CAD that runs entirely in the browser. No installation, no
account, and nothing is sent to a server — every model stays on your device.

**Live: https://cartacad.com**

- Sketching with a real constraint solver
- Parametric feature history — extrude, revolve, fillet, chamfer, shell, patterns
- Assemblies with a simultaneous mate solver
- Papercraft unfolding with printable cut-and-fold sheets
- Bilingual interface (English / Hebrew)

## About this repository

This repository holds the **built site only**: one self-contained HTML file with
every library inlined, so the page loads on any network with no CDN dependency.
The source is maintained separately.

## Updating

Replace `index.html` with a newly built bundle and commit. GitHub Pages
publishes within a minute or two.
